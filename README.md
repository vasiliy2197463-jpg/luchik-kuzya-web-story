# Лучик и Кузя — история дружбы

Небольшая адаптивная интерактивная веб-страница о котах Лучике и Кузе. Проект создан как аккуратная переработка первых учебных сайтов: с понятной структурой, документацией, семантической разметкой и небольшим JavaScript-интерактивом.

## Возможности

- адаптивная вёрстка для компьютеров и телефонов;
- семантический HTML и доступные элементы управления;
- интерактивное переключение трёх глав;
- фотоглава с 16 снимками и фильтрами «Еда», «Игры» и «Прогулки»;
- просмотр фотографий в увеличенном формате;
- встроенная MP4-анимация с элементами управления;
- фирменный курсор в виде лапки над фотографиями;
- поддержка настройки `prefers-reduced-motion`;
- отсутствие внешних библиотек и зависимостей.

Откройте `index.html` в браузере. Дополнительная установка не требуется.
